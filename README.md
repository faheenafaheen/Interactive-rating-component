# Interactive Rating Component

A rating card where the user picks a score and sees a thank-you state after submitting.

This is my solution to the [Frontend Mentor](https://www.frontendmentor.io) challenge "Interactive rating component".

## Live Demo and Code

- **Live site:** https://faheenafaheen.github.io/Interactive-rating-component/
- **Repository:** https://github.com/faheenafaheen/Interactive-rating-component

## The challenge

Users should be able to:

- Select and submit a number rating
- See the "thank you" state after submitting
- View the best layout on different screen sizes
- See hover and focus states for interactive elements

## Built with

- Semantic HTML5
- CSS custom properties and Flexbox
- JavaScript for the selection and submit state

## What I practised

- Handling selected and submitted states with JavaScript
- Styling hover, active and focus states
- Responsive component design

## Run it locally

```bash
git clone https://github.com/faheenafaheen/Interactive-rating-component.git
cd Interactive-rating-component
```

Open `index.html` in your browser. No build step is needed.
